# CO_CHECKLIST — Checklist VLAN

App web instalável no celular (PWA) com os KPIs do **Checklist VLAN**, atualizados a cada 5 minutos: fila, frentes de atividade,
acertos e erros, acompanhamento do dia e a saúde dos bancos e da máquina da API. Só abre pelo login do **HUB dos apps**.

Publicado pelo GitHub Pages em <https://wro1984.github.io/CO_CHECKLIST/>. Os números vêm cifrados do Worker da Cloudflare, publicados
pelo MAPI (`wro1984/mapi5`, `checklist_app.py`, ver `CHECKLIST_APP.md` de lá). **Leia o `CLAUDE.md` antes de mudar qualquer coisa.**
